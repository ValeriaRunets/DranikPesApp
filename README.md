# Драник-трекер 🐶

Приложение для двоих, чтобы вместе трекать обучение пса Драника командам:

- 🦴 **Сегодня** — список команд с отметкой «выполнили» в один-два тапа
  (дома 🏠 или на улице 🌳), добавление своих команд с категориями
  🎉 весёлые / 🎓 полезные;
- 📊 **Статистика** — графики за день / неделю / месяц: какие команды
  тренируем много, а какие заброшены, активность по дням, кто из вас
  больше занимается с Драником;
- 💧 **Туалет** — отметки «плохих» событий (на пелёнку, мимо пелёнки,
  на асфальт), стрик «дней без промахов» и тренд к нулю.

Маскот — мультяшный Драник собственной персоной 🐾

## Как это устроено

Статический сайт (Vite + React + TypeScript + Tailwind + Recharts), хостится
на GitHub Pages. Данные — в бесплатной облачной базе [Supabase](https://supabase.com),
поэтому вы оба видите одни и те же отметки с любых устройств. Логина нет:
при первом запуске каждый выбирает «кто ты», выбор запоминается на устройстве.

Пока Supabase не настроен, приложение работает в **локальном режиме**:
данные хранятся в браузере (localStorage) и не синхронизируются между
устройствами. Это удобно, чтобы просто посмотреть приложение.

## Запуск локально

```bash
npm install
npm run dev
# откроется на http://localhost:5173/DranikPesApp/
```

## Настройка общей базы (Supabase) — ~5 минут

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) (бесплатный план)
   и создайте новый проект.
2. В проекте откройте **SQL Editor → New query**, вставьте содержимое файла
   [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run** — создадутся
   таблицы и стартовый набор команд.
3. Откройте **Project Settings → API** и скопируйте два значения:
   - `Project URL` (вида `https://xxxxx.supabase.co`)
   - `anon public` ключ
4. В репозитории на GitHub: **Settings → Secrets and variables → Actions →
   New repository secret** — добавьте два секрета:
   - `VITE_SUPABASE_URL` — Project URL
   - `VITE_SUPABASE_ANON_KEY` — anon-ключ
5. Перезапустите деплой (вкладка **Actions → Deploy to GitHub Pages → Run
   workflow**) — и приложение переключится на общую базу.

Для локальной разработки с общей базой скопируйте `.env.example` в
`.env.local` и впишите те же значения.

> ⚠️ **Про приватность.** Anon-ключ попадает в собранный сайт, а правила
> доступа в базе открытые — любой, кто узнает адрес вашей базы и ключ,
> сможет читать и менять данные. Для семейного трекера тренировок это
> осознанный компромисс ради простоты (без регистраций и логинов).
> Не храните здесь ничего чувствительного.

## Публикация на GitHub Pages

1. В репозитории: **Settings → Pages → Build and deployment → Source** —
   выберите **GitHub Actions**.
2. При каждом пуше в `main` workflow из
   [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) соберёт и
   выложит сайт на `https://<ваш-логин>.github.io/DranikPesApp/`.

На телефоне сайт можно добавить на главный экран («Добавить на экран
“Домой”») — он установится как приложение со значком Драника.

## Структура

```
src/
  lib/            типы, слой данных (localStorage / Supabase), даты
  components/     маскот, шторки, формы, навигация
  pages/          Сегодня · Статистика · Туалет · Онбординг
supabase/schema.sql   схема базы + стартовые данные
.github/workflows/deploy.yml   деплой на GitHub Pages
```
